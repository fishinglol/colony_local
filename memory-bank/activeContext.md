## How a turn runs now
- Direct chat and `# mix` (message with or without images/PDFs): app → `POST /api/turns/prepare` (`core/native_turn.py`: decider when no `role_id`, `ensure_agent`, persona files, unseen team context + capability text, attachments, fence) → `GatewayClient.chat` (WebSocket: status, deltas, tool steps, approvals) → `POST /api/turns/finish` (saves to the shared conversation, memory keep, seen marker). Code: `ColonyStore.runDirect`.
- Fallback (`POST /api/messages` → `core/chat.py`, HTTP chat-completions): used when `prepare` says `native:false` (video/audio, missing file, Gateway not ready), when the Gateway cannot be reached at all, with `colonyDirectGateway=false`, and by the web UI/Tauri. Still guarded by colony-gate.
- Slash commands (`/status`, `/skill …`): menu from Gateway `commands.list`, agent's own chat only; sent as typed; the command and its reply are dropped from the context agents get (`context.drop_commands`).

## Handoff between agents (2026-10-13)
Agents are told their teammates (name + `when`, `capability_text(teammates=…)`). A role with `accepts_handoff` (default off; Coucou Settings → agent → Tools) can be handed a task: when an agent's reply LAST line starts with `@Name task` (name or id, any case, not itself, target accepts), `POST /api/turns/finish` returns `handoff {role_id, role_name, message, from, hops}`; the app (`ColonyStore.send` loop) then calls `prepare` with `role_id`+`handoff_from`+`hops` and runs that teammate in the same conversation. Colony enforces it, not the app: `prepare` refuses a target that does not accept, an unknown sender, or `hops > MAX_HOPS` (3); `finish` offers no handoff once `hops` hit 3. The task is saved as the teammate's reply only (`append_exchange(user_message=None)`; metadata `handed_by`, `decided_by: handoff`), never as something the user said; no `keep_if_worth` for it. HTTP fallback (`core/chat.py`) and web UI do not hand off (teammates are listed with accepts=False there). Sequential only. No OpenClaw `sessions_spawn` (child sessions would not reach the shared conversation).
Owner-verified on Coucou 2026-10-14 (chain Coder → Thinker → Writer, `/new`, write asks). Verified live 2026-10-13 through Colony + Gateway with `gemma4:31b` (prepare → `/v1/chat/completions` → finish → handoff → Bo's turn → conversation has no fake user row). One handoff per reply (the LAST line); a model asked to involve two teammates may skip the first. Not tried: small models like nemotron following the "last line @Name" rule.

## /new clears the conversation shown (2026-10-13)
`/new` (group chat or an agent's room; first word of the saved command) → `native_turn.finish` calls `history.archive_before(ws, keep_last=2)`: every earlier message goes to `~/.colony/archive/<workspace_id>/<UTC timestamp>.json` (written before anything is removed) and `history.json` keeps only the `/new` exchange, so `GET /workspaces/{id}/messages` (which returns everything, unbounded) and Coucou stay short. OpenClaw's own `/new` only archives the agent's model session, not Colony's conversation. The sqlite mirror (write-only, unused for reads) still holds the old rows. No restore command yet: the archive is plain JSON. `unseen()` copes with the vanished seen-marker. Does not apply to the HTTP fallback/web UI (no slash commands there).

## Facts that are easy to get wrong
- `~/.colony/.env` env vars: real shell env wins. Tests must not read the real `.env` (conftest blanks keys, sets `PROJECTS_DIR`).
- `GatewayClient` keeps its device key in the Keychain; a freshly compiled unsigned test binary waits forever on a Keychain prompt (looks like a WebSocket hang; Gateway log: `handshake timeout … ws_upgrade_started`). Test copies must swap `deviceKey()` for a file.
- A `gateway-client`/`backend` WebSocket client is "headless": exec approvals fail. Use `client.id=openclaw-macos`, `mode=ui` with a device identity.
- The OpenClaw source folder `openclaw-main 2/` is gitignored; Colony starts the Gateway from it (needs Node ≥24.16).
- A new workspace without a `folder` gets `~/Documents/Colony Projects/<name>`; `folder: ""` means chat only.
- Memory, SOUL.md, approvals, compaction, MCP are OpenClaw-side — don't rebuild them in Colony.
